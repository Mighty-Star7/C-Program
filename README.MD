# This C program is just for testing

A simple C application developed using Visual Studio Code and MingGW to practice if/else

## Features

- Prompts the user to input a number.
- If the number choosen is lower than 10, it displays that the number is lower than 10.
- If the number choosen is higher than 10, it displays that the number is higher than 10.

## Tech Stack

- ***Language:*** C
- ***IDE:*** Visual Studio Code
- ***Complier:*** GCC (MinGW)
